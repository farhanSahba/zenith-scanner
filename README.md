# ⚡ Zenith — ماسح الضاربة اللحظي

ماسح أسهم أمريكي لحظي لتداول الزخم اليومي (مثل Zenda/Trade Ideas)، مبني على **Next.js 15 + TypeScript**،
مع **محرّك محاكاة سوق واقعي** يعمل فوراً بدون أي اشتراك، ومزوّد داتا خلف **Adapter** جاهز للـ real-time،
و**طبقة ذكاء Claude العربية** (تحليل محفّزات + راوي سيتَب + ماسح بلغة طبيعية + تنبيهات صوتية).

---

## التشغيل السريع

```bash
npm install
npm run dev
```

ثم افتح <http://localhost:3000>. يعمل مباشرةً على **بيانات محاكاة** — لا تحتاج أي مفتاح.

## ما الذي تراه

| العنصر | الوصف |
|---|---|
| **Momo HOD** | أسهم تصنع/تختبر قمة اليوم بزخم صاعد |
| **Gap Up** | الفجوات الصاعدة فوق العتبة |
| **Gap Up LowFloat** | فجوات صاعدة بفلوت منخفض (أكثر انفجاراً) |
| **2 min Momo UP / DOWN** | أقوى قفزة/هبوط خلال دقيقتين |
| **لوحة التنبيهات** | `To HoD`، `+X% /2Min`، `-X% /2Min` لحظياً |
| **الرسوم** | TradingView (15د + 1د) مع مستويات VWAP / HoD / PM-High |
| **الماسح الذكي (عربي)** | اكتب فلترك بالعربية → يُترجم ويُطبّق |
| **الأخبار** | مع زر «تحليل Claude» (زخم سليم مقابل تخفيف) |
| **🔊 الصوت** | نطق التنبيهات الجديدة بالعربية |

### الأعمدة ومعانيها

- **ZenV**: ميل الـ VWAP (أخضر صاعد / أحمر هابط)
- **ZenP**: الاحتمالية المركّبة 0–100 (زخم + حجم + قرب من القمة + سيولة)
- **ZenVR**: الحجم النسبي (الفعلي ÷ المتوقّع بهذا الوقت)
- **AtrVwap / AtrHoD**: بُعد السعر عن الـ VWAP وعن قمة اليوم بوحدات ATR
- **AtrSprd**: السبريد ÷ ATR (ضيّق = سيولة جيدة)
- **Float / Rot**: الفلوت ودورانه (الحجم ÷ الفلوت)
- **القاعدة الذهبية**: كل الأعمدة خضراء → الصف يُبرَز (أعلى احتمال)

> إشارات للعناية الواجبة — ليست توصية تداول.

## تفعيل الداتا الحقيقية (Alpaca)

في `.env.local`:

```bash
DATA_PROVIDER=alpaca
ALPACA_KEY_ID=مفتاحك
ALPACA_SECRET_KEY=سرّك
ALPACA_FEED=iex          # مجاني (بورصة واحدة) | sip (مدفوع، كل البورصات)
# قائمتك المركّزة (أو مخرجات فلترك الليلي):
ALPACA_SYMBOLS=AAPL,TSLA,...
# الفلوت (Alpaca لا توفّره) — من مصدرك:
ALPACA_FLOATS=TSLA:3180,AAPL:15200
```

> المنطق كله خلف واجهة `MarketAdapter` واحدة. التبديل بين المحاكاة والـ real-time = متغيّر بيئة واحد.
> لترقية لاحقة إلى SIP المجمّع الكامل (Polygon/Massive) أو Databento: نفّذ نفس الواجهة في `src/engine/adapters/`.

## تفعيل طبقة Claude العربية

```bash
ANTHROPIC_API_KEY=مفتاحك
AI_MODEL=claude-opus-5-5   # أو claude-haiku-5-5 للسرعة
```

بدون مفتاح، يعمل النظام بمحلّل **قواعدي عربي بديل** (بلا تكلفة) لكل ميزات الذكاء.

## البنية

```
src/
  engine/
    adapters/        المزوّدات: simAdapter (محاكاة) + alpacaAdapter (حقيقي) + المصنع
    ai/              طبقة Claude: catalyst (المحفّزات) · narrate (السيتَب) · nlquery (الماسح العربي)
    symbolState.ts   حالة كل رمز: VWAP, ATR, HoD, بارات, تاريخ الأسعار
    snapshot.ts      حساب الأعمدة + الألوان + ZenP + القاعدة الذهبية
    scanner.ts       تصنيف اللوحات الخمس
    alerts.ts        كشف الأحداث (To HoD / 2Min) مع تهدئة
    engine.ts        المنسّق: tick → حالة → snapshot (كل ~600ms)
  app/
    api/stream       بث SSE لحظي
    api/chart        بيانات الرسم (1د + 15د)
    api/ai           طبقة الذكاء (narrate | catalyst | nlquery)
    page.tsx         لوحة القيادة الكاملة
  components/        اللوحات، الجداول الملوّنة، التنبيهات، الرسوم، الماسح الذكي
```

## معادلات الأعمدة

```
VWAP     = Σ(سعر×حجم) / Σ(حجم)
ATR      = متوسط المدى الحقيقي (14 بار × 1د)
AtrVwap  = (السعر − VWAP) / ATR
AtrHoD   = (قمة اليوم − السعر) / ATR
AtrSprd  = (Ask − Bid) / ATR
Gap%     = (الافتتاح − إغلاق أمس) / إغلاق أمس
2Min%    = تغيّر السعر خلال آخر دقيقتين
ZenVR    = الحجم التراكمي ÷ المتوقّع بهذا الوقت
ZenP     = مزيج موزون (زخم 22% · حجم 18% · قرب القمة 18% · VWAP 14% · سبريد 10% · دوران 10% · ميل 8%)
```
